# Tes images

Dépose tes images dans ces dossiers en respectant **exactement** les noms ci-dessous
(formats acceptés : .jpg, .jpeg, .png, .webp, .avif). Relance `npm run dev` si le jeu
tournait déjà. Tu peux aussi importer une image directement dans le jeu avec les
boutons 🖼️ : une image importée dans le jeu passe avant celle du dossier.
